# Elora Store

A girls-focused fashion & lifestyle e-commerce frontend built with React, Tailwind CSS, React Router, Axios and Context API.

## Stack
- React + Vite
- Tailwind CSS v4
- React Router
- Axios
- Context API
- DummyJSON API
- Lucide React
- LocalStorage

## Run
```bash
npm install
npm run dev
```

## Main structure
src/components:
Categories, Footer, Hero, Navbar, NewArrivals, Newsletter, ProductCard, Promo

src/context:
AuthContext, CartContext, ThemeContext, WishlistContext

src/pages:
Cart, Checkout, Home, Login, NotFound, ProductDetails, Register, Shop, Wishlist

src/services:
ProductServices.js
